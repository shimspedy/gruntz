# Gruntz audit — October 31, 2026

Security audit (quick profile, full report outside the repo at `~/security-audit-skill/gruntz/run-1/`) plus a code-health pass. Design and app behaviour are unchanged except where noted.

## Security fixes
- **Trial start:** a future `trial_started_at` written to the user's own backup row could grant an unlimited trial on a fresh device. The app now ignores future starts; the database clamps them and keeps the earliest start.
- **Team chat:** the server sets message time, takes the display name from the roster, and limits a member to 30 messages a minute per team.
- **Team membership:** joins, leaves and removals lock the team row, so concurrent calls cannot exceed caps or leave a team without a leader (reproduced before the fix on local Postgres).
- **Reports:** a report keeps a database-made copy of the reported message, so deleting the message, account or team no longer erases it. Privacy policy updated.
- **Invite codes:** cryptographically random, leader can reset them, and wrong guesses are limited to 20 an hour per account. Codes stay six characters for older app builds; on those builds a wrong code now looks like a silent no-op instead of an error.
- Supabase session stored in the Keychain/Keystore; notification links limited to `gruntz://`; CSV export formula guard and import size cap; Sentry redacts ids and emails from error text; avatar bucket forced private; shared stats bounded.

## Code health
- Fixed a crash when editing a set that was just removed. Handled failures (backup, Health sync, route migration, persistence) now reach Sentry.
- Stricter TypeScript (`noImplicitOverride`, `noImplicitReturns`, `noFallthroughCasesInSwitch`, `noUnusedLocals`, `noUnusedParameters`); ESLint (`eslint-config-expo`) added to `npm run check`.
- Removed unused code, `lottie-react-native`, `react-native-webview`, the node-forge fork (upstream 1.4.2 has the fix) and the no-longer-needed Expo JSI patch. Safe in-range dependency bumps; Node 24.
- CI: read-only token, SHA-pinned actions, concurrency, Dependabot. `npm run security:audit` fails on any advisory except two documented build-tool advisories accepted until 2027-01-31.
- Website: HSTS, long-lived cache for hashed assets, responsive hero photo, Astro 7.4.
